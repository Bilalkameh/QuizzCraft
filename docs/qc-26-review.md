## Public catalog trace

React builds the filtered read URL and links to play with the stable quiz ID. Vite proxies `/api` to Spring Boot in development. [Catalog.jsx:25, 62, 151](../frontend/src/catalog/Catalog.jsx#L25), [vite.config.js:6](../frontend/vite.config.js#L6)

The security filter chain permits GET and HEAD for categories, catalog and numeric quiz detail. Registration and login are public. Maker, play and submission routes require a valid bearer JWT, with an additional ADMIN role rule for `/api/admin/**`. The decoder validates signature, issuer, expiry, subject and role. `AuthController.me` uses the validated subject as the account ID. [AuthSecurity.java:43, 72–78, 108–118](../backend/src/main/java/com/quizzcraft/auth/AuthSecurity.java#L108), [AuthController.java:46–48](../backend/src/main/java/com/quizzcraft/auth/AuthController.java#L46)

[CatalogController.java:29–43](../backend/src/main/java/com/quizzcraft/catalog/CatalogController.java#L29) binds typed optional filters, wraps rows in `items`, and translates a missing detail into 404. [CatalogRepository.java:14–37, 45–63](../backend/src/main/java/com/quizzcraft/catalog/CatalogRepository.java#L14) owns parameter binding, eligibility, format aggregation and row mapping. List and detail share the same SQL. It follows `quizzes.latest_published_revision_id` and requires a published revision of the same active quiz. Filters and question count apply to that revision. Retired categories still join. This is a cohesive read path, and the thin controller can delegate directly to the repository.

[CatalogQuiz.java:5–6](../backend/src/main/java/com/quizzcraft/catalog/CatalogQuiz.java#L5) serializes exactly `quizId`, `revisionId`, `title`, `description`, `category` (id, name, status), `difficulty`, `format` and `questionCount`. Detail returns one such object. The query aggregates question types and counts. It never joins the choices table, where [schema.sql:61–67](../backend/src/main/resources/schema.sql#L61) stores `is_correct`. Both public reads expose metadata only.
